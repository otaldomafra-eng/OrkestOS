1. Origem do projeto

O projeto foi clonado a partir do repositorio open-source:
https://github.com/aaryan498/WiseMindOS

A ideia original do WiseMindOS era um sistema all-in-one de produtividade e life management, com:
- metas;
- projetos;
- tarefas;
- planejamento diario;
- habitos;
- foco;
- biblioteca/notas;
- analytics;
- assistente FutureTwin.

O projeto foi escolhido como base para criar uma versao adaptada chamada OrkestOS.

2. Direcao do produto

A direcao definida foi:

Sistema completo por funcionalidade, minimalista por interface.

Ou seja, o OrkestOS nao deve ser um app simples demais. Ele pode ter muitos modulos, mas a experiencia deve ser limpa, direta e organizada. A referencia conceitual e um "sistema operacional pessoal" com tarefas, habitos, metas, foco, notas, calendario/rotina e automacoes.

4. Acesso demo

Como o projeto pede login/cadastro e ainda depende de backend/MongoDB para autenticacao real, foi adicionado um modo demo local.

Na tela de login existe o botao:
Entrar como demo

Esse botao cria uma sessao local temporaria com:
- nome: Usuario Demo
- username: demo
- email: demo@orkestos.local

Isso permite testar a interface sem configurar banco de dados ou criar usuario real.

Como acessar:
1. Abrir http://127.0.0.1:5173/
2. Clicar em Entrar
3. Clicar em Entrar como demo
